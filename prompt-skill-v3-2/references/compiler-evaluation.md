# 编译可解性与评测合同

## 结果状态

- `SUCCESS`：输入、素材、权限和入口能力足以唯一编译，并通过内部对账。
- `BLOCKED_MISSING_ASSET`：缺少锁定人物、产品、场景、声音、首尾帧或其他不可替代资产/授权。
- `BLOCKED_UNSOLVABLE`：导演锁互相冲突、时间/物理不可执行、参考权威无法唯一化，或当前入口不支持必要模式。
- `FAILED`：读取、编译、验证或文件处理过程失败。

阻断不是失败表演。列出证据、受影响字段和最小补充，不越权找素材、不编造标签、不伪造平台能力。

## 人类先定义底层 Eval

先从真实生成结果中由人类定义“为什么不可用”的底层标准，再让模型协助归类和批量评分。至少分：

- 人物身份；
- 产品几何、标签与材质；
- 开口、台词、发音、口型和发声主体；
- 动作物理、接触因果与语义手势；
- 随机文字、字幕与音轨污染；
- 镜头/时间轴、连续性和闭合终态；
- 局部编辑目标准确性与非目标保护。

AI 可以压缩反馈，不能凭空发明审美、品牌风险、合规或业务正确性的标准。

## 一致性不等于正确性

同一 Prompt 多次生成用于测随机性。多数输出一致，只能证明模型稳定解释了输入；必须继续对照 `DIRECTOR_LOCK`、原始静态真值和业务验收。若多次稳定出现同一错误，回查 Prompt 歧义、参考权限或导演合同，不能按多数票放行。

## 拓扑版本化 Eval

`single-shot`、段内多镜、分段续接、局部编辑、画幅重构和批量 Agent 是不同系统。模型、入口、模式、参考绑定或生成拓扑变化时，测试集和指标随版本更新；不能用单镜成功外推多镜、续接或局修可靠性。

能力与可靠性分开：

- 能力：多次尝试中是否至少能完成；
- 商业可靠性：首轮成功率、最差失败、平均返修轮数、单位可用镜头成本。

回归集保留能区分版本的困难样本；所有版本都通过或都失败的样本不应主导决策。

## 局修验收顺序

1. 指定目标是否改对；未完成即失败。
2. 未授权时间窗和非目标区域是否保持。
3. 身份、产品、物理、口型、声音与连续性是否仍成立。
4. 成片是否满足当前业务和交付层要求。

漂亮、流畅或大部分区域未变，不能补偿目标准确性失败。

## 可追踪断言

评测断言使用稳定 ID，记录范围、证据和结果。不要报告无法映射到具名断言的裸通过分数；测试数量、生成单元数量和产物数量分别统计。

## 分通道验收与可比证据

视觉验收先静音检查身份、产品几何/文字、接触、连续性与终态；再独立核对对白、环境声、动作声和音乐，最后合看同步、声音桥与完整表达。静音仅隔离视觉缺陷，不能据此判定声音主导的叙事不成立，也不能用配乐掩盖画面失败。

先核对交付类型与导演锁是否一致，再评估美观。重复出现的文字、时序、参考绑定失败交由外部执行流程增加相应检查；OCR只是辅助，未运行就不能宣称已验收，不能靠继续堆负面词替代检查。

比较模型或版本时记录供应方、入口、版本、日期、时长、分辨率、音频配置、参考角色、抽样次数、选片方式和后期处理。条件不同必须披露，单次成功不能推导成功率。保留需求/合同、Prompt、真实设置、资产版本、实际工具调用、既有授权、结果、返修与人工结论的最小证据；缺项写未知，凭据不入记录。
