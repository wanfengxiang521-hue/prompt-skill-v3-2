# 参考素材合同

## 动态视频输入边界

默认禁止第三方动态视频参考。对标、拉片、预演、动作视频、摄影机视频和多格分镜视频只用于离线分析，不得作为生成模型的引用输入。镜头顺序、动作轨迹、动作速率和剪辑节奏必须由文字完整描述；允许使用静态人物、产品、场景、首尾帧和批准的静态轨迹图。自有前段视频的受限续接条件见 [compiler-mode-and-compile.md](compiler-mode-and-compile.md)。

## 标签原样保留

逐字保留参考标签：仅限用户或入口实际提供的标签；不得翻译、转写、改大小写、改空格、重编号、纠错或凭空创建。通用 Skill 中不预写任何示例标签，避免模型把示例误当成真实素材。

## 资产注册表

可复用人物、产品、地点、声音和视觉系统先建立唯一 `asset_id` 与 `version`。注册表记录：实际标签、授权状态、可见内容、权威字段、不可控制字段、验证日期和当前可用入口。每个生成单元只激活当前真正需要可见或可听且不可替代的最小资产集。

模板或检索得到的 Prompt 只能作为候选，记录来源、版本、适用模型、被改写字段和验证结果；它不拥有人物/产品真值，也不能绕过导演锁。

## 参考权限矩阵与优先级图

每个素材建立三组字段：

- `allowed_fields`（允许控制）：该素材可以控制的字段，如身份、产品几何、服装、环境、首帧、尾帧或声音；
- `forbidden_fields`（禁止控制）：该素材不得迁移的字段，如人物身份、背景、标志、色彩、摄影机、动作或音频；
- `priority`（冲突优先级）：同一字段发生竞争时的明确权威顺序。

每个目标字段只能有一个最终权威源。一个源可以拥有多个字段，但不能让两个源同时争夺同一字段。没有任何权威字段的素材应从当前单元删除。若冲突无法通过字段拆分和优先级唯一解决，返回 `BLOCKED_UNSOLVABLE`，不靠“都参考一下”模糊处理。

推荐句式：`[原样标签/资产ID] 仅控制 [允许字段]；禁止控制 [字段]；与 [其他参考] 冲突时，[具体字段] 以 [权威源] 为准。`

## 常见权威关系

- 原始人物图控制稳定身份；经过确认的静态尾帧只控制暂态起点。
- 原始产品图控制外形、比例、标签位置和材质；运动参考不得覆盖产品几何。
- 动作节奏、身体路径和摄影机路径全部由逐秒文字时间窗控制，不建立视频参考职责。
- 造型图可控制服装/发型安排，但不得覆盖人物图拥有的脸、体型、肤质和稳定身份。
- 场景图可控制空间结构、材质和主光方向，但不得迁移其中人物、产品、品牌和文字。
- 批准的静态箭头分镜、关键点或路径图默认只作分析参考：将已锁定轨迹转成文字，不把标注图作为普通图片引用。只有入口已核验提供不参与外观生成的专用控制通道时，才可按其权限输入；不得覆盖人物/产品身份。
- 音频参考控制节奏、说话方式或声相时，明确哪些画面元素不随之迁移。

## 画面文字处置合同

对每类可见文字逐项标记：

- `must-preserve`：产品真值中的原包装图形与文字，只继承、不重写、不翻译、不镜像、不补字、不杜撰；
- `illegible`：手机屏幕、远处店招等非叙事文字，允许存在但不可读、不可成为视觉重心；
- `forbidden`：自动字幕、随机标题、乱码、角标、贴纸字、弹幕、额外 Logo/水印、价格和促销字；
- `add-in-post`：运营字幕、CTA、证书说明、活动信息等后期添加并人工校对的文字，生成画面中保持无字或不可读承载面。

“纯净母版”不等于删除产品真实包装。必须把包装真值与未经授权的生成文字分开处理。

## 多主体与可审计性

多主体参考必须用位置、角色、服装或其他稳定可见特征锁定目标，不能默认中央或最大人物。无法真实查看素材时，标注为“用户描述”，不要声称已经观察；角色不明确就阻断。

仅使用用户拥有、获授权、公共领域、合规素材库或明确允许的身份、声音、品牌和表演参考。上传本身不等于授权。

## 分析图与干净生成参考

提交前区分真实场景/包装文字与人为控制标记：箭头、面板编号、时间码、字幕、拼贴边框不属于外观真值。普通图片输入不能靠负面词保证这些像素不被复制。优先使用对应原始干净素材；需要清理时在已获授权范围处理，并验收身份、几何、包装文字、构图与原图一致后重新绑定版本。不得擅自重绘或把真实包装字当污染擦掉。

只有标注图且缺少必要干净资产时标为 `BLOCKED_MISSING_ASSET`，说明缺哪项；不声称清理已完成。不需要绑定的分析图可留在分析层，不因其存在无谓阻断。

音频单独登记对白、环境声、动作声、音乐的来源、权威、优先级与可删性；不因声源不可见而删音频，不因画面嘴部可见而覆盖锁定旁白。不擅自增加音乐。
