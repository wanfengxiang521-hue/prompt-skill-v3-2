# 模型机制与单变量修复

以下是用于编译和诊断的工作模型，不是对未公开架构的事实声明。

## 八个机制

1. **注意力是预算**：可见主体、动作和终点优先；泛化形容词会稀释权重。
2. **熟悉分布更稳定**：稀有组合应拆成清晰的物理关系，不靠“高级、电影感”解决。
3. **否定词较弱**：优先写应当出现的正向替代；把必要禁项集中在合同末端。
4. **时间依赖轨迹**：一个原因、连续后果、明确终点，比多个断裂微动作更易执行。
5. **误差会累积**：连续生成用原始参考重新锚定，不能把错误代代放大。
6. **参考源在重叠维度通常强于文字**：不要用近似文字重复参考画面；写角色边界与变化量。
7. **细节能力受屏幕面积影响**：关键脸、手、产品和标志必须在导演合同允许的构图中占够面积；不足则阻断，不擅自换镜头。
8. **音画共同占用约束**：对白、嘴型、头部运动、摄影机运动和其他声源同时复杂时更容易冲突。

## 症状到修复变量

| 症状 | 先改一个变量 |
|---|---|
| 长提示词仍很泛 | 删除泛词，提前主体—动作—终点 |
| 动作跳步或糊成一团 | 保留一条因果轨迹，减少并行主动作 |
| 人物或产品漂移 | 回到原始参考，收紧其权威维度 |
| 参考素材互相污染 | 重写 `reference_roles` / `reference_exclusions` |
| 已完成动作被重演 | 强化 `completed_beats` 与实际起态 |
| 未来动作提前 | 强化 `reserved_beats` 与停止条件 |
| 对白嘴型或声音不同步 | 只在合同许可范围内降低同轨竞争；否则阻断退回上游 |
| 小字、手部或标志损坏 | 先检查屏幕面积；不得私自改导演镜头 |
| 续拍越接越偏 | 停止错误链，回到原始参考和最近验收尾态 |
| 新旧要求互相打架 | 显式写新规则替换旧规则并从最终 Prompt 删除旧规则 |
| 局修整体更漂亮但没改对 | 先过目标准确性门，不用美观分补偿目标失败 |
| 尾部手/道具继续抖动 | 先完成接触解除、回弹与闭合终态，再允许保持 |

每轮修复只改变一个编译变量或不可分割的耦合变量组，并保留其他条件，用结果判断真正主因。耦合变量组必须命名，例如“声源—口部状态”或“手指接触—泵头回弹”，不能把镜头、表演、参考角色、风格和动作混成一个大改动。

## 显式替换语义

返修 Prompt 不得只在旧 Prompt 后追加相反要求。使用固定合同：

`新规则 X 替换旧规则 Y；从最终提交文本删除 Y 及其同义冲突句；未列出的锁定项保持不变。`

提交前验证：旧规则及同义冲突残留为零，新规则只影响获准时间窗与对象，不改变导演锁指纹。

## 时间寻址局部修复

局修写成：

`开始时间—结束时间 × 目标人物/产品/区域 × 唯一待改属性 × 必须保持项`

验收顺序固定为：

1. 目标准确性：指定修改是否真实完成；未完成即失败。
2. 非目标保护：其他时间窗、人物、产品、构图、台词、声音和节奏是否无回归。
3. 现实感：接触、运动、材质和口型是否物理可信。
4. 时空/音频：连续性、声相、声音桥和终态是否仍成立。

若当前入口没有被现场验证的局部编辑或逐帧保护能力，不得把重新生成称为“只改这一段”；返回能力阻断或改走上游批准的替代方案。

## 返修顺序

1. 先按剧情事实与单元边界验收，不先用“好不好看”掩盖越界。
2. 对照 `endpoint`、停止条件和四区防火墙，定位重演、漏演或提前。
3. 再检查身份、产品、动作物理、表演、摄影、声音与口型。
4. 给失败归一个主类别，只修改对应的一个编译变量。
5. 保留其余输入、参考和导演锁不变后重跑；若主因在导演合同，退回导演阶段重新锁定，不在编译层偷改。

## 返修停止规则

每轮开始前声明：

- 具名成功阈值及证据；
- 本轮唯一允许变化项与保持清单；
- 最大轮次与预算上限；
- 达到阈值后的停止动作；
- 无改善时的升级去向。

达到成功阈值立即停止。同一变量连续两轮没有降低违规次数或严重程度时，停止换措辞，依次检查：入口能力、参考权限冲突、关键区域屏幕面积、导演合同可执行性、模型/模式适配。需要改变镜头、台词、表演策略、节拍或终态时退回导演层；需要换入口或模式时进入模型选择层。不能无限追加形容词。

## 修复职责路由

- 语义、顺序、动作句法或约束冲突 → Prompt 编译修复；
- 关键构图或路径真值错误 → 修正批准的静态分镜/轨迹资产并重新编译；
- 局部瑕疵且入口支持 → 时间寻址局修；
- 导演节拍、表演、镜头或时长本身不可执行 → 退回 `$director-skill-v2-2`；
- 字幕、CTA、调色、音轨替换或版式 → 后期层；
- 入口不支持、素材缺失或真值冲突 → `BLOCKED_UNSOLVABLE` / `BLOCKED_MISSING_ASSET`。
