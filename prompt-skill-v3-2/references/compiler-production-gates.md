# 生产门与外部工作流边界

本文件定义 Prompt 编译前后需要存在、但不得写进生成模型提示词的生产控制。控制流外置：分支、重试、工具调用、状态保存、成本、批准、QC、后期和发布均留在工作流层。

## 渐进保真门

高成本视频生成前，先用最低成本的可用产物验证高风险项：

1. 静态人物/产品/场景真值与首帧验证身份、构图、产品朝向、标签保护、画幅和文字污染。
2. 信息流广告可先独立生成 3—5 秒钩子，验证首个视觉锚点、人物脸、声音和主动作；钩子不通过，不扩展完整片。
3. 通过后才编译完整生成单元。

是否执行试片由导演/生产工作流决定；本 Skill 只消费已批准结果，不擅自新增镜头或付费调用。

## 正式产物人工批准门

代理可以提出 Prompt 候选和返修差异，不得静默覆盖已批准版本。涉及模型、模式、资产、费用或投放变化时，先核对本任务已有授权与预算；范围内继续执行，不重复请求同一批准。超出范围时先完成可审阅候选、理由与差异，再请求最小补充授权。导演锁状态、素材QC、用户授权和发布批准分别记录，不能互相代替。

## 成本与产物边界

全链路成本拆分为策划/LLM、静帧、视频、配音、素材、剪辑、局修和返工；单次模型调用价不等于完整广告成本。成本核算、扣费和支出日志不进入模型 Prompt。

接口返回成功只证明任务状态，不证明成片可用。工作流层继续检查文件存在、容器/编码、时长、抽样帧、音轨、语义动作和商业验收。

## 生成—后期交接

每个通过的生成单元在工作流层记录：

- clip/unit ID 与对应导演锁版本；
- 人物、产品、场景真值版本；
- 实际时长、可剪入口/出口和闭合终态；
- 台词/旁白、环境声、动作声和音乐状态；
- 字幕/随机文字污染状态；
- 后期时间线位置和待完成项。

运营字幕、CTA、证书说明、调色、版式和必要的音轨替换在后期完成并人工校对。

## Delivery Mutation Profile

投放平台可能在生成后自动叠加字幕、卡片、CTA、商品图、音乐、AI 标签或免责声明。`surface_profile` 记录这些变换能否关闭、能否预览和最终交付需要额外执行的 delivered-ad QC。模型 Prompt 的无字约束不能控制平台后生成叠加。
