# 模式选择与编译顺序

## 本工作流的动态视频输入边界

默认禁止第三方动态视频参考。对标、拉片、预演、动作示范、摄影机示范和多格分镜视频只用于离线分析，不得作为生成模型的引用输入；静态人物、产品、场景、首尾帧和批准的静态轨迹图可以按权限使用。镜头顺序、动作轨迹、动作速率和剪辑节奏必须由文字完整描述。

`V2V`、`edit` 与 `extend` 不是通用默认模式。只有自有或已授权输入、导演锁明确需要、当前入口/账号/地区现场核验支持且风险可接受时才可选择；对标或第三方视频永不因此获得生成权威。

## 模式门

| 模式 | 使用条件 | 文字主要承担 |
|---|---|---|
| `T2V` | 没有视觉源，合同允许从文字建立状态 | 完整可见起态、动作轨迹、终态 |
| `I2V` | 一张图控制起始外观或构图 | 时间变化、摄影机、声音、终态 |
| `V2V` | 仅限已授权且导演锁明确要求的视频变换 | 允许变化量、保护项、停止点 |
| `R2V` | 多模态参考分别控制身份、产品、动作、镜头或声音 | 精确角色边界与不迁移项 |
| `FLF2V` | 已有明确第一帧和最后一帧 | 中间因果路径与禁止越界项 |
| `edit` | 已核验入口支持对既有视频做局部修改 | 目标区域、单一变化、其余保护 |
| `extend` | 已核验入口支持原生延长且前段已验收 | 已观察尾态、延续向量、本段终态 |

模式名不等于平台保证。对实际使用入口运行时核验功能、字段、时长和引用方式。无法核验时使用 `surface_profile: 保守档`：一次只处理一个紧凑生成单元，保留用户原始标签，不声明固定参考数量、固定分辨率、局部编辑、逐帧保持或原生扩展能力；导演锁的目标时长可以保留为创作目标，但不得冒充平台已保证的精确能力。

## Surface Profile V2

每次编译记录：

- `surface`、`model_version`、`account_or_region`、`mode`；
- `verified_at`（验证日期）与 `evidence_grade`：`marketing / live_ui / successful_task`；
- 已核验时长、画幅、参考类型/数量、首尾帧、声音、口型、局部编辑、延长和输出格式；
- `delivery_mutation_profile`：投放或平台是否可能在生成后自动叠加字幕、卡片、CTA、商品图、音乐、AI 标签或免责声明，是否可关闭和预览。

营销内容只产生候选能力。实际编译只使用当前入口、账号/地区、模式下由 `live_ui` 或 `successful_task` 支持的能力。最大容量不是推荐用量。

## 可解性门

开始编译前选择一个结果：

- `SUCCESS`：导演锁、素材和入口能力足以唯一编译；
- `BLOCKED_MISSING_ASSET`：缺少被锁定且不可替代的素材或授权；
- `BLOCKED_UNSOLVABLE`：入口能力、真值冲突或物理/时长合同使任务不可执行；
- `FAILED`：编译或验证过程本身失败。

阻断时列证据与最小补充，不编造标签、素材、平台能力或伪结果。

## source-carries-state

有已验收参考源时，源承担它能可靠携带的状态，文本只写变化量：

- 仅当受限自有视频续接条件全部满足时，已验收前段可以携带动态相位；文字仍需写新动作、终点、保护项和排除项，人物/产品/场景身份回连原始静态真值。
- 最后一帧只携带静态尾态；文字还需写开放中的主体运动、摄影机运动和声音相位。
- 没有可见源时，文字必须重建必要起态，但不能把未观察的计划状态冒充已发生状态。

## 编译顺序

若用户锁定的是一个固定时长生成单元（例如一个 15 秒段落），先把段内镜头和声源变化编译为同一提示词中的连续时间窗，不得按内部切镜拆成多个提交任务；用户要求拆分或入口限制要求调整时，必须先由导演层修订生成单元并重新锁定；编译器不得自行改变拓扑。

1. 锁定模式、模型原生编译目标、`surface_profile` 和可解性状态；
2. 写实际参考标签，或用户明确提供的占位标签，以及 `reference_roles`、`reference_exclusions`；
3. 写源角色与源无法携带的 `start_state`；
4. 写主体、`current_action`、最短因果链和 `endpoint`；
5. 写锁定的摄影机、调度、光线、对白和声音；发声主体先服从 `dialogue_contract`。只有合同明确委托达人默认映射时，才用“嘴部可见 → 本人同期口播，嘴部不可见 → 同一声线旁白，无文案 → 环境声/动作声”；
6. 写 `preservation_locks`、`completed_beats`、`reserved_beats`、`do_not_show`；
7. 写局部负面提示词：禁止新增任何字幕和未经授权的画面文字，同时保护产品真值参考中的原有包装；
8. 写明确停止条件。

编译后必须按 [v3-output-contract.md](v3-output-contract.md) 在内部核验锁定合同一致性、时长负载、四区防火墙与生成后验收顺序，再生成目标模型纯提示词。默认只交付提示词；只有用户明确要求编译审计时，才分开输出内部检查摘要。

每个时间窗把动作、表演、摄影、光线和声音作为并行轨道描述；不要把并发约束误写成一串必须顺序完成的事件。动作细化为轨迹、速率相位、接触响应和终点，摄影机写明信息动机与运动终点。

## 模型原生编译与控制流外置

导演锁保持模型无关，最终 Prompt 必须针对当前模型、入口和模式重新编译。跨模型或模式迁移时，用同一小样分别验证规格服从、参考绑定、动作完成、口型/声音、文字污染和终态；禁止把旧 Prompt 原样复制并假设等价。

控制流外置：分支、重试、预算、工具调用、状态保存、批准、QC、拼接和发布属于工作流/编排层。交给生成模型的 Prompt 只描述当前生成单元的参考、画面、动作、表演、摄影、光线、声音、终态和约束。

## 压缩顺序

保留优先级从高到低：

1. 精确参考标签、角色边界、身份与产品保护；
2. 源无法携带的实际起态；
3. `current_action`、因果响应、`endpoint`；
4. 导演锁定的关键表演行为；
5. 连续性锁与镜头/运动开放相位；
6. `completed_beats` 与 `reserved_beats` 排除；
7. 对白、口播声源、口型同步、声音和停止条件；
8. 禁止新增任何字幕的负面提示词与产品包装文字保护；
9. 仍对叙事有用的环境与风格锚点。

先删重复描述、抽象赞美、同义形容词、参考源已经显示的背景、未来剧情摘要和内部解释。不能为了变短删除终态、角色绑定或改变导演意图。提示词字数不等于时长；评估的是时间轨道与串行转换，不是汉字数量。

停止条件、口播声源映射、口型同步和无字幕负面提示词都属于不可压缩项。说明本单元在哪个可见或可听状态停下，以及哪些后续事件尚未发生。压缩后再次核验 `completed_beats`、`current_action`、`endpoint`、`reserved_beats` 四区互斥。
