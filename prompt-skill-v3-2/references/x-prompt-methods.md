# X 提示词方法合成

本文件只保留可跨项目复用的方法，不复制任何创作者的完整提示词，也不携带特定人物、品牌或业务脚本。

## 一项素材，一个权威角色

每个参考素材只对明确维度拥有最终控制权，同时写出排除项：

`实际标签/资产版本 → 权威角色 → 允许控制的字段 → 禁止控制的字段 → 冲突优先级`

同一字段不能有两个互相竞争的权威源。没有权威角色的素材不进入当前生成单元。未提供的参考标签不得臆造。

## 指令密度不等于顺序事件密度

长提示词可以精细描述同一时刻并发的身份、服装、光线、构图、材质、环境声和连续性，这些不必逐项占用时间。真正挤压时长的是必须依次完成的动作、对白、判断、接触和转场。

先把信息分为并发约束与顺序事件密度，再用多轨证据判断能否在目标时长内完成，不能按汉字数量估时。

## 把动作写成物理因果链

主要动作按以下顺序描述：

`可见起态 → 主动部位与方向 → 轨迹 → 速率相位 → 接触点 → 接触响应 → 惯性/残留 → 可确认终态`

速率不是单个“快/慢”标签，可写启动、加速、制动、停稳。接触响应要说明物体、人或表面如何真实受力，不用抽象效果词代替。

## 用可观察表演替代情绪标签

不要命令人物“悲伤、愤怒、感动”。先写人物目标、阻力和触发，再写：目光落点、反应延迟、呼吸、肌肉抑制、未完成动作、策略改变、非自愿泄漏和结束后的状态残留。

可观察表演必须能被镜头看见或声音听见，并服务当前戏剧行动。

## 摄影机服从观众信息变化

摄影机只在以下至少一项变化时移动：新信息进入、注意力转移、权力位置变化、空间关系打开或关闭。每次运动写清：起始触发、路径、速度阶段、焦点/景深变化、终点构图和停稳条件。

没有信息变化就锁机；镜头风格名不能替代空间与运动合同。

## 声音是动作时钟与剪辑桥

对白、呼吸、接触声和环境声可标记动作是否完成；声音桥可以跨切点保持时间连续；响度、混响与声相可以提示远近和景深关系。把声音节点绑定到可见动作，不在画面完成后再硬塞声音。

## 转场必须可见或可听

不要只写“自然转场”。说明转场由什么动作、遮挡、构图对应、光线变化或声音桥触发，以及转场后保留了什么连续状态。

## 结构暴露冲突，不制造品味

字段化记录用于检查：谁控制什么、什么已经发生、当前做到哪里、未来不得出现什么、哪里超载。审美与叙事取舍仍由导演层决定，不能靠堆字段自动生成。

## 失败分类与单变量修复

先判断失败属于身份/产品漂移、动作跳步、表演直白、镜头无因、连续性重演、未来动作提前、音画冲突或时长超载。每轮只修改一个最相关变量，并保持其余条件不变，用新结果确认因果。

返修使用显式替换，不把相反要求继续叠加在旧 Prompt 后：`新规则 X 替换旧规则 Y，删除 Y；未列锁定项保持不变`。先检查指定目标是否改对，再检查非目标保护。

## 干净母版与文字处置

先正向定义只包含获准人物、产品、环境和包装真值的纯净母版，再集中排除生成字幕、标题、UI、乱码和未经授权文字。产品包装、非关键屏幕文字、禁字和后期文字分别使用 `must-preserve / illegible / forbidden / add-in-post`，不靠一句“不要字幕”解决所有文字职责。

## 模型原生编译与外部评测

同一导演锁迁移到不同模型、入口或生成拓扑时重新编译，并用带验证日期的能力证据和对应回归集验收。多次输出一致只证明模型稳定解释了输入，不证明表达正确；最终仍以导演锁、静态真值和业务验收为外部权威。
