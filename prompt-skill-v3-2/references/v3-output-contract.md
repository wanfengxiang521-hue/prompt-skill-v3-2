# V3 输出合同

默认按生成单元输出。默认最终交付只输出可直接复制给生成模型的纯提示词，禁止把完整 `DIRECTOR_LOCK`、内部推理、导演分析、未来剧情摘要、验收说明或使用说明混入交付内容。

默认禁止第三方动态视频参考。对标、拉片、预演和分镜视频只用于离线分析，不得作为生成模型的引用输入；使用已授权的静态人物、产品、场景、首尾帧或静态轨迹真值。镜头顺序、动作轨迹、动作速率和剪辑节奏必须由文字完整描述。受限自有前段续接必须满足入口、授权、导演锁和 QC 条件。

用户指定一个固定时长生成单元（例如一个 15 秒段落）时，该段只有一个模型提交区块。段内可以用多个时间窗承载切镜、转场和声源切换，但不得按内部切镜拆成多个提交任务；用户要求拆分或入口上限迫使拆分时，先由导演层修订生成单元并重新锁定；编译器不自行改变拓扑。

## 默认最终交付形态

```markdown
[静态人物/产品等实际参考标签，或用户明确提供的静态占位标签，及其权威角色与排除项]
[必要起态]
[按时间窗组织的主视觉锚点、动作、表演、摄影、光线、声音、对白或口播]
[锁定的发声主体、口型与声源切换]
[闭合终态与停止条件]
[只保留本单元的高风险约束]
[集中负面提示词：禁止新增字幕和未经授权的画面文字；保护产品真值参考]
```

导演决定必须翻译为模型可执行语言。单个生成单元只交付一份纯提示词；多个生成单元分别交付独立纯提示词，不在提示词前后添加结论、说明或验收意见。

## 内部检查结构

生成最终提示词前，在内部核验 `锁定决定与时长负载`、`completed_beats`、`current_action`、`endpoint`、`reserved_beats` 和 `生成后验收顺序`。锁定决定摘要、时长负载、连续性防火墙和验收清单仅在内部使用，不进入默认交付。

只有用户明确要求查看编译分析或审计信息时才单独输出，并与可复制提示词分开；不得让人类审阅内容污染模型提交文本。导演方案与分镜请求必须转交 `$director-skill-v2-2`。

## 模型提交层写法

先写实际参考角色和必要起态，再按目标时长写连续时间窗。每镜保留锁定的视觉锚点与观看关系；只有已锁定视觉变化时，才编译其进入、变化与终态。纯静态或声音主导镜头保留不变画面与锁定声音进程，不制造视觉动作。时间窗围绕锁定的主注意力组织，可并行说明表演、摄影、光线和声音，也可保持已有状态。

高风险动作使用状态跃迁句法：`初始状态 → 触发 → 接触/受力 → 位移与速度 → 可见结果 → 人物反应 → 声音落点 → 闭合终态`。表演使用可观察行为；运镜写动机、触发、路径、速率相位、焦点或景深变化与终点；声音按导演锁绑定动作节点、独立声音进程或声画并置关系。末尾写清闭合终态和停止条件，不得用完整故事结尾代替当前单元终点。

## 达人口播声源合同

口播声源首先服从锁定的 `dialogue_contract`，编译器不能替上游重新选择同期口播或画外旁白。只有合同明确委托采用达人默认映射时，才根据嘴部可见性编译：

- 锁定脚本中的台词原文逐字保留；没有当前用户对本段的明确改写授权时，一个字都不得增删替换，也不得用先前对其他版本或其他段落的压缩授权推定本段可改。

- 嘴部清晰可见且当前时间窗分配了文案：当前文案由画中同一人物本人开口，口型、下颌、呼吸、重音和停顿同步。
- 人物未出镜或嘴部不可见但当前时间窗仍承载文案：同一声线无缝转为画外旁白；后脑、头皮/发际线极近景、手部、产品、手机、花材和环境空镜都属于嘴部不可见。
- 当前时间窗没有分配文案：可以不安排旁白，只保留环境声和动作声；不得让人物无声持续动嘴。
- 同一句跨切点：声线、语速和语气连续，不重说；切回嘴部可见镜头立即恢复同期口播。
- 口播结束：人物闭口，只保留自然呼吸；不得无声持续动嘴。
- “表现力强”不得原样进入模型提示词；必须编译成关键词重音、语速相位、音高/音量变化、停顿、呼吸、眼神、眉眼、头部动作、手势节拍和句后残留。

导演锁若明确人物可见但闭口、台词由画外声承担，本 Skill 按锁编译；若它同时又声明达人默认映射，属于上游冲突，必须退回导演层，不能静默覆盖其中任一项。

## 无字幕与画面文字合同

先建立正向纯净母版：画面只出现当前获准的人物、产品、环境和包装真值，不生成任何运营文字层。再为每个可提交单元集中写一次 `负面提示词`，至少禁止新增字幕、自动字幕、逐字字幕、标题、角标、贴纸字、弹幕、未经授权水印/Logo、UI、价格、促销字、乱码、伪文字、文字底板和字幕条。

画面文字逐项使用 `must-preserve / illegible / forbidden / add-in-post`：产品真值参考中的原有包装图形与文字为 `must-preserve`，不被无字幕规则删除；模型只能继承真实参考，不得重写、翻译、镜像、补字或杜撰。非关键屏幕文字为 `illegible`；随机字幕等为 `forbidden`；证书说明、运营字幕、价格、CTA 或活动文字为 `add-in-post`，生成画面中保持空白或不可读，不写“字幕安全区”。

负面提示词只能降低错误概率，不能承诺百分之百无字幕、无乱码或无随机音乐。生成后把画面文字、口型/发声主体、身份/产品和音轨分别验收；供应商或投放平台强制的 AI 标签、C2PA、隐形水印和免责声明不与模型乱码混为一谈。

用户明确提供的占位标签允许出现在工作稿中，但必须逐项写明权威角色与排除项，并提示提交前替换为平台真实标签。未得到用户明确占位指令时，不得自创标签。

## 隐藏与保留

用户只要最终提示词时，必须隐藏完整导演合同、计算明细、`lock_conformance` 和四区防火墙；内部仍须完成 `SCRIPT_LOCK → DIRECTOR_LOCK → compile` 检查。跨段任务在内部保留四区防火墙，最终只把它产生的可执行约束编译进对应纯提示词。

如果用户请求导演方案或分镜，转交 `$director-skill-v2-2`；本合同不输出导演方案。

## 闭合终态

运行时保持、补时或尾帧停留只能从闭合终态开始：人物和手停止在命名位置，道具/产品完成接触解除、回弹或停稳，摄影机到达终点，台词结束后闭口，动作声和声音桥完成收束。保持段禁止继续动作、再次接触、重演、说新台词或提前下一拍。
