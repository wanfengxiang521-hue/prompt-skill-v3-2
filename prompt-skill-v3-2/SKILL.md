# 提示词 Skill V3.2

版本：3.2。调用名为 `prompt-skill-v3-2`；兼容原 Codex 1.2 与增强 1.3 导演合同。技能版本不等于合同族版本。

## 任务边界

把状态为 `locked` 的 `DIRECTOR_LOCK v1` 编译为当前生成模型可直接执行的提示词。编译只翻译、排序、压缩和绑定已锁定决定，不得新增任何导演决定。

本 Skill 无权新增或修改剧情、镜头、导演节拍、表演策略、人物调度、摄影机动机与路径、主视觉锚点、光线、声音、剪辑、对白或终态。平台限制若与导演锁冲突，必须报告冲突并退回 `$director-skill-v2-2`；不能在提示词中偷偷补导演。

## 必需输入

开始编译前取得：

- `DIRECTOR_LOCK.contract_family: "DIRECTOR_LOCK v1"`、兼容版本、唯一 ID 与 `lock_status: locked`。
- 依赖的 `SCRIPT_LOCK` 版本、不可改变事实、锁定对白和禁止项。
- 当前 `generation_unit`、时长、`START → MOTION → END`、四条时间轨与停止条件。
- 当前生成模型或入口的已核验 `surface_profile`；无法核验时使用保守档。
- 用户实际提供且当前入口真实可用的图片、音频、首尾帧或其他参考素材及原始标签。

不得臆造标签、素材、入口能力、时长上限或模型功能。信息缺失导致多种创意答案时停止，不推断导演决定。

## 缺少导演锁时

当用户只提供脚本、分镜或表达简报，却直接要求最终提示词时，先使用 `$director-skill-v2-2` 生成并锁定 `DIRECTOR_LOCK v1`，随后回到本 Skill 编译。中间合同可以在最终交付中隐藏，但必须真实完成并通过导演层检查。自然语言没有字段化不等于任务不可解；只有导演层也无法唯一锁定时才阻断。

本 Skill 不得为了“先给一个能用的版本”自行补齐表演、调度、摄影、光线、声音、剪辑、视觉锚点或节拍。`lock_status` 不是 `locked` 时，只返回缺失字段与冲突，不输出试运行提示词。

## 编译工作流

### 1. 验证导演锁

按 [compiler-director-lock-input.md](references/compiler-director-lock-input.md) 检查合同族、版本、ID、事实锁、导演总纲、镜头、生成单元、连续性、时长证据、风险和 `lock_status`。

先区分合同结构变体，不能只凭 `version: 1.3` 接受 Hermes 的异构合同。商业扩展存在时核验 claims、shot_proofs、koc_inserts、truth_boards；缺决定性字段退回导演层，未批准板或缺真实素材标为 BLOCKED_MISSING_ASSET。

编译前记录不可变指纹：剧情事实、镜头数量与顺序、每镜职责、观众信息增量、主视觉锚点、表演、调度、摄影、光色、声音、剪辑、锁定对白、连续性与终态。编译后逐项比对。

### 2. 建立运行时编译上下文与可解性状态

先记录 `surface_profile` 的入口、模型版本、账号/地区、模式、验证日期、证据等级、时长、画幅、参考、声音、编辑和交付后变换。营销页面只能产生候选能力；实际编译只使用现场 UI 或成功任务已验证的能力。

只在已核验入口内选择 `T2V`、`I2V`、仅含授权静态图片/音频的 `R2V`、`FLF2V` 或已核验的 `edit/extend`。默认禁止第三方动态视频参考；对标、拉片、预演和分镜视频只可离线分析。自有且通过 QC 的前段视频只有在导演锁明确要求原生续接、入口已核验且用户有权使用时，才能作为受限动态状态源；身份、产品和场景真值仍回连原始静态锚。

编译前判定：`SUCCESS`、`BLOCKED_UNSOLVABLE`、`BLOCKED_MISSING_ASSET` 或 `FAILED`。入口能力不足、素材缺失或真值冲突时报告证据，不把不支持的能力伪装成文字约束。

### 3. 隔离当前生成单元

一次只编译当前 `generation_unit`，在内部明确隔离四个区：

- `completed_beats`：已经完成，不得重演。
- `current_action`：本轮唯一主要动作因果链。
- `endpoint`：本轮必须确认的终态和停止条件。
- `reserved_beats`：未来节拍，本轮不得提前发生。

四区在内部必须显式存在，默认最终交付时不显示字段名，只把它们编译成必要起态、当前动作、排除项、闭合终态和停止条件。

一个固定时长生成单元可以包含多个内部剪辑镜头，但不得仅因内部切镜就拆成多个提交任务；拆分需求先退回导演层修订并重新锁定；已核验入口限制只说明必须调整，不授权编译器自行拆分。生成拓扑、镜头顺序和切点全部服从导演锁。

源时间轴截取到已锁定的连续单元时，所有轨道统一换算为本地时间 `t_local = t_source - unit_start`；保持时长、相对偏移、切点和停顿，不压缩重排。已有本地时间不重复减偏移；跨边界事件缺少交接状态时退回导演层。详见连续性参考。

### 4. 绑定参考素材

每项真实参考素材必须进入参考权限矩阵：原始标签或资产 ID/版本、允许控制、禁止控制、冲突优先级、授权状态。每个目标字段只能有一个最终权威源；只激活当前单元不可替代的最小参考集。

参考增删、重排、版本或职责改变时，原绑定失效，重新编译并对账；保持已获授权范围。多页面或多产品只绑定通过验收的静态真值板及槽位映射，不让模型自动去重。

逐字保留用户或界面中的真实标签；占位标签只在用户明确要求时使用，并提示提交前替换。静态人物、产品、场景、首尾帧和批准的静态轨迹图可按权限使用；动作轨迹、速率、镜头顺序和剪辑节奏必须由文字完整描述。

带箭头、面板编号、时间码或讲解文字的图默认只作分析输入；普通图片入口使用已验收的干净参考，控制信息转为文字。不得误删原包装真值文字，也不得擅自重绘资产。详见参考合同。

### 5. 编译为模型可执行语言

按以下顺序编译，不改变导演决定：

`主体与起态 → 当前动作状态跃迁 → 速率相位 → 接触/受力与材质响应 → 可观察表演 → 调度 → 机位与构图 → 运镜与焦点 → 光线与色彩 → 声音与口型 → 闭合终态 → 停止条件`

先分别核对人物、服装和道具状态：持有者、位置、可用性及已锁定的接触/交接事件。缺失前因不得靠补动作修复；没有物理变化的隐喻、静态镜头或声画并置，不强制增加动作因果。

删去内部解释词，保留模型执行所需的可观察名词、动词、方向、速度、接触、时间窗和状态。导演意图可以压缩，导演决定不能省略或替换。

### 6. 锁定对白、声源与口型

锁定台词必须逐字保留。未获授权时，不得增字、删字、换词、合句、拆句或同义改写。

发声主体首先服从锁定的 `dialogue_contract`，编译器不得用嘴部可见性覆盖上游决定。只有导演锁明确委托采用达人默认映射时，才使用：嘴部清晰可见且当前有文案 → 画中本人同期口播；人物未出镜或嘴部不可见且文案继续 → 同一声线画外旁白；无文案 → 环境声与动作声。上游合同与用户已锁定规则冲突时阻断并退回导演层。

### 7. 建立画面文字与纯净母版合同

对画面内每类文字标记：`must-preserve`、`illegible`、`forbidden` 或 `add-in-post`。产品真值图中的原包装文字通常为 `must-preserve`，但不得重写、翻译、镜像、补字或杜撰；运营字幕、标题、CTA 和促销信息默认 `add-in-post`。

每个提交单元用正向纯净母版定义“只出现被授权的人物、产品、环境和包装真值”，再集中禁止未经授权的字幕、自动字幕、标题、角标、水印、UI、乱码、伪文字、文字底板和字幕条。负面词只降概率，不承诺百分之百无字；生成后必须独立验收文字污染。

只加入与当前单元风险相关的局部负面约束，不能用一长串抽象禁令替代正向物理描述。

### 8. 编译后对账

逐项确认：

- 没有新增镜头、事件、人物、动作、对白或视觉锚点。
- 没有改变镜头顺序、表演策略、调度、摄影机路径、光色、声音、剪辑或终态。
- 当前单元没有重演 `completed_beats`，也没有提前发生 `reserved_beats`。
- 所有引用只控制获授权维度。
- 提示词包含闭合终态、停止条件和局部负面提示词；运行时补时只能从人物、道具、摄影机和声音均已收束的闭合终态开始。

任何一项不一致都阻断输出。

### 9. 单变量返修与显式替换

生成失败时先分类为输入、身份、产品、参考冲突、动作物理、语义手势、口型/发音、文字、声音、密度、连续性、模型机制、后期或输出格式问题。一次只修改一个耦合变量组并保持不可变指纹；不得在返修中重新导演。

返修必须采用显式替换：`新规则 X 替换旧规则 Y，删除 Y；未列出的锁定项保持不变`。时间寻址局修写明时间窗、目标对象/区域、唯一待改属性和保持清单；先过目标准确性门，再验非目标保护、现实感、时空与音频。

每轮开始前声明成功阈值、最大轮次和预算上限。达到阈值立即停止；同一变量连续两轮无改善时，升级到入口能力、参考资产、导演合同或模型选择层，不继续堆词。

若失败来自导演锁本身不可执行，退回 `$director-skill-v2-2` 产生新版本合同，再重新编译。

## 输出规则

- 默认最终交付只输出可直接复制给生成模型的纯提示词，不附解释、分析、摘要、审计字段、验收清单或使用说明。
- 用户明确要求查看编译审计时，审计与纯提示词分开输出。
- 多段视频逐段独立输出，只把上一段实际验收终态传给下一段。
- 最终提示词采用正向固定形态：`参考绑定 → 必要起态 → 时间窗执行 → 发声与声音 → 闭合终态 → 高风险保护 → 集中负面块`。
- 完整 `DIRECTOR_LOCK v1`、时长计算、四区防火墙和内部对账默认不进入最终提示词。

## 硬门槛

- 输入必须是状态为 `locked` 的 `DIRECTOR_LOCK v1`；缺失时先使用 `$director-skill-v2-2`。
- 编译器不得新增任何导演决定，也不得以平台适配为由重写导演决定。
- 当前单元只执行 `current_action`，不重演过去，不预演未来。
- 每个主要动作保留 `START → MOTION → END`、速率相位和必要接触响应。
- 每次运镜保留锁定动机、触发、路径、速度相位和终点。
- 锁定对白逐字不变；时长冲突只能报告或退回导演层。
- 每个单元都有可见或可听的 `endpoint` 和明确停止条件，不能以“时间到了”结束。
- 参考素材只控制获授权维度，不迁移其中无关人物、品牌、背景、动作或摄影。
- 默认禁用视频引用；静态真值参考可以使用，动作和镜头必须由文字完整编译。
- 默认禁止第三方动态视频参考；受限自有续接必须同时满足导演锁、入口能力、用户权利和 QC 条件。
- 每个单元必须包含画面文字四态合同、正向纯净母版与集中的未经授权文字/字幕负面提示词。
- 参考素材必须有允许字段、禁止字段和冲突优先级；一个字段只能有一个最终权威。
- 运行时保持或补时只能从闭合终态开始。
- 模型、模式或生成拓扑改变时必须模型原生编译并使用对应回归集；不能直接复制旧 Prompt 并假设等价。
- 控制流外置：分支、重试、预算、工具调用、批准、QC 和发布留在工作流层，不进入生成模型提示词。
- 失败返修一次只改变一个编译变量；导演锁错误必须退回 `$director-skill-v2-2`。
